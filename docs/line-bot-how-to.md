# วิธีใช้ TravelAss LINE bot

ใช้ได้ทั้งในกลุ่ม (เรา 2 คน + บอท) และแชท 1:1 กับบอท
ในกลุ่มบอท **เงียบ** กับแชทปกติ — ตอบเฉพาะข้อความที่มีตัวเลข, รูป, หรือขึ้นต้นด้วยคำสั่ง
ข้อมูลมาจาก **ทริปที่สถานะ "กำลังเที่ยว"** เท่านั้น

> ไปจีนแผ่นดินใหญ่: ใช้ eSIM ท่องเที่ยว (หรือโรมมิ่ง/VPN) — ซิมจีนเปล่าๆ ใช้ LINE ไม่ได้

---

## 1. บันทึกค่าใช้จ่าย

### ข้อมูลที่ต้องมี
| ข้อมูล | ถ้าไม่บอก |
|---|---|
| **ยอดเงิน** | บอทถาม |
| **สกุลเงิน** | บอทถาม (ปุ่ม HKD / THB) |
| **คนจ่าย** | ใช้คนที่ส่งข้อความ (ชื่อ LINE ต้องตรงกับชื่อสมาชิกในแอป ไม่ตรง → บอทถาม) |
| **หาร** | บอทถาม (ปุ่ม ไม่หาร / หารเท่า / หารไม่เท่า) |
| หมวด | บอทเดาเอง (แก้ได้ในการ์ดสรุป) |
| โน้ต | คำที่เหลือในข้อความ |

### การหาร
| แบบ | ความหมาย |
|---|---|
| **ไม่หาร** | คนจ่ายจ่ายของตัวเอง |
| **หารเท่า** | แบ่งครึ่ง 2 คน |
| **หารไม่เท่า** | อีกคนฝากจ่ายบางส่วน — บอทถาม "ฝากจ่ายเท่าไหร่?" |

### พิมพ์แบบไหนก็ได้
```
120                              → ถาม สกุลเงิน → หาร
120 ข้าวมันไก่                    → ถาม สกุลเงิน → หาร
120 บาท ข้าวมันไก่ ไม่หาร          → ไม่ถามอะไร ไปการ์ดสรุปเลย
120 HKD ข้าว หาร                 → หารเท่า
500 บาท เซเว่น ฝาก 20             → หารไม่เท่า อีกคนคืน 20
```
คำสกุลเงิน: `HKD` `hk` `ดอลฮ่องกง` = HKD · `บาท` `฿` `THB` = THB

### ส่งรูปสลิป
ส่งรูป → บอทถามยอด → สกุลเงิน → หาร → การ์ดสรุป
(พิมพ์ยอดตามมาภายใน 30 นาที บอทรวมเข้ากับรูปให้)

### การ์ดสรุป
```
120 HKD (~540฿) · 🍜 อาหาร
👤 เก่ง จ่าย · หารเท่า: โอคืน 270฿
[✅ ยืนยัน] [✏️ แก้] [🗑 ยกเลิก]
```
- **✅ ยืนยัน** → บันทึกเสร็จ
- **✏️ แก้** → เลือกข้อที่จะแก้ (ยอด / สกุลเงิน / คนจ่าย / หาร / หมวด / โน้ต)
- **🗑 ยกเลิก** → ลบรายการ

### ระหว่างทาง
| พิมพ์ / กด | ผล |
|---|---|
| ↩ ย้อน | กลับไปแก้ข้อก่อนหน้า |
| `ยกเลิก` | เลือก ลบทิ้ง / เก็บไว้กรอกทีหลัง |
| `ทำต่อ` | กลับมากรอกรายการที่ค้าง |
| `แก้ล่าสุด` | เปิดการ์ดสรุปของรายการล่าสุดที่เราบันทึก |

- เงียบเกิน 30 นาที → รายการค้างอยู่ในคิว "รอกรอก" ในแอป ไม่หาย
- กำลังกรอกอยู่แล้วพิมพ์คำสั่งดูข้อมูล (เช่น `แพลน`) ได้ — รายการที่กรอกค้างยังอยู่
- เริ่มรายการใหม่ทั้งที่อันเก่าค้าง → บอทถาม ทำต่ออันเก่า / เก็บไว้ก่อน / ทิ้งอันเก่า

## 2. แพลน — `แพลน` หรือ `plan`

| พิมพ์ | ได้อะไร |
|---|---|
| `แพลน` | แพลนวันนี้ |
| `แพลน พรุ่งนี้` · `แพลน เมื่อวาน` | วันนั้น |
| `แพลน 20/11` · `แพลน 20 พ.ย.` | วันที่ระบุ |
| `แพลน วันที่ 3` | วันที่ 3 ของทริป |
| `แพลน ศุกร์` | วันศุกร์ในทริป |
| `แพลน 2` · `#2` | รายละเอียดรายการที่ 2 ของวันที่ดูล่าสุด |
| `แพลน พรุ่งนี้ 2` | รายการที่ 2 ของพรุ่งนี้ |
| `ต่อไป` | รายการถัดไปจากเวลาตอนนี้ |
| `ตอนนี้` | รายการที่อยู่ในช่วงเวลานี้ |

**การ์ดภาพรวม:** เวลาเริ่ม–จบ · ชื่อ · สถานที่ · สี: เขียว = เสร็จ, ฟ้า = ถัดไป, เทาขีดฆ่า = ข้าม
แตะแถว → รายละเอียด · ปุ่ม ◀ วันก่อน / วันถัดไป ▶ · ปุ่มแพลนสำรอง (ดูอย่างเดียว)

**การ์ดรายละเอียด:** รูป (แตะขยาย) · โน้ต (อ่านต่อ) · การเดินทาง · การจอง
ปุ่ม: Google Maps · 高德 Amap · ดูรูปทั้งหมด · **✓ เสร็จ / ↩ ยังไม่เสร็จ** · ก่อนหน้า / ภาพรวม / ถัดไป

ข้าม / ย้ายวัน / สลับแพลน → ทำในแอป

## 3. ตั๋ว / การจอง / เอกสาร — `จอง` `ตั๋ว` `เอกสาร`

| พิมพ์ | ได้อะไร |
|---|---|
| `จอง` | การจองทั้งหมด (ที่ผ่านแล้วอยู่ท้าย) |
| `ตั๋วเครื่อง` | เครื่องบิน |
| `การจองโรงแรม` · `เอกสารการจองโรงแรม` | โรงแรม |
| `การจองรถ` · `ตั๋วรถ` | รถ |
| `จอง กิจกรรม` | กิจกรรม |
| `ตั๋ว ดิสนีย์` | ค้นชื่อ / เลขจอง |
| `จอง พรุ่งนี้` · `จอง 21/11` | การจองของวันนั้น |

**การ์ดรายละเอียด:** รูป (แตะขยาย) · **เลขจองตัวใหญ่** · วันเวลา (โรงแรม: เช็คอิน–เช็คเอาท์, กี่คืน) · ค่าใช้จ่าย · คนจ่าย
ปุ่ม: **📋 คัดลอกเลขจอง** · ดูรูปทั้งหมด · ดูในแพลน

> พิมพ์ `ตั๋วรถ 50` (มีตัวเลขที่ไม่ใช่วันที่) → บอทถาม "บันทึกค่าใช้จ่าย หรือ ค้นการจอง?"

## 4. ร้านอาหาร / ที่เที่ยว

| พิมพ์ | ได้อะไร |
|---|---|
| `ร้าน` · `ร้านอาหาร` · `กิน` | ร้านอาหาร |
| `ที่เที่ยว` · `อยากไป` · `สถานที่` | ที่อยากไป |
| `ร้าน มงก๊ก` | กรองย่าน / ค้นชื่อ |
| `ร้าน ต้องลอง` · `ที่เที่ยว ดาว` | เฉพาะที่ติดดาว |
| `ร้าน ยังไม่ไป` · `ร้าน ไปแล้ว` | กรองตามสถานะ |

เลื่อนการ์ดซ้าย-ขวา · แตะรูปเพื่อขยาย
ปุ่ม: Google Maps · 高德 Amap · รูปทั้งหมด · **✓ ไปแล้ว / ↩ ยังไม่ไป**

> `กินข้าว 120` → บอทถาม "บันทึกค่าใช้จ่าย หรือ ค้นร้าน?"

## 5. ข้อมูลด่วน — `ข้อมูล` หรือ `ข้อมูลด่วน`

| พิมพ์ | ได้อะไร |
|---|---|
| `ข้อมูล` | ทั้งหมด (ปักหมุดก่อน) |
| `ข้อมูล wifi` · `ข้อมูล โรงแรม` | ค้นหัวข้อ / ค่า |

ปุ่มท้ายแถว: 📞 โทร (เบอร์) · 🔗 เปิดลิงก์ · 📋 คัดลอก
การ์ดเดี่ยว: ค่าตัวใหญ่ + ส่งข้อความธรรมดาให้กดค้าง copy · ปุ่ม **🔍 โชว์ตัวใหญ่** ไว้ยื่นให้คนขับ/พนักงานดู

## 6. โน้ต — `โน้ต`

| พิมพ์ | ได้อะไร |
|---|---|
| `โน้ต` | รายการหัวข้อ |
| `โน้ต วีซ่า` | ค้นหัวข้อ / เนื้อหา |

การ์ดเนื้อหา: 12 บรรทัดแรก · ปุ่ม **อ่านเต็ม** (ส่งเป็นข้อความ) · รูป

---

## 7. การเดินทาง — `เดินทาง`

| พิมพ์ | ได้อะไร |
|---|---|
| `เดินทาง` | การเดินทางวันนี้ |
| `เดินทาง พรุ่งนี้` · `เดินทาง 21/11` | วันนั้น |
| `เดินทาง ดิสนีย์` | ค้นต้นทาง / ปลายทาง |
| `รอบต่อไป` | เที่ยวถัดไปของวันนี้ |

**การ์ดรายละเอียด:** รอบออก (รอบที่ผ่านขีดฆ่า, รอบถัดไปไฮไลต์ "อีก 12 นาที") · จุดขึ้นรถ + รูป · ทางเลือกสำรอง · ค่าเดินทาง
ปุ่ม: **Google Maps นำทาง** (จากตำแหน่งปัจจุบัน) · **高德 Amap** (ใช้ในจีน — กรอกชื่อสถานที่เป็นภาษาจีนในแอปจะค้นเจอง่ายกว่า) · ดูในแพลน

## 8. อื่นๆ

| พิมพ์ | ผล |
|---|---|
| `เมนู` · `?` | การ์ดสอนใช้ + ปุ่มลัดทุกคำสั่ง |

- ทุกคำสั่งพิมพ์ `ขอดู` / `ขอ` นำหน้าได้ เช่น `ขอดูแพลนพรุ่งนี้`
- ไม่มีทริป "กำลังเที่ยว" → บอทบอกให้เปลี่ยนสถานะทริปในแอปก่อน
- แก้ไขข้อมูลส่วนใหญ่ทำในแอป — LINE ทำได้แค่: บันทึกค่าใช้จ่าย, ติ๊กแพลนเสร็จ, ติ๊กร้าน/ที่เที่ยวไปแล้ว
